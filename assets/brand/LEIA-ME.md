# Tasca: identidade visual

- `tasca-icon.svg`: ícone principal (vetor, usar sempre que possível)
- `tasca-icon-small.svg`: versão simplificada para 16 a 32 px
- `tasca.ico`: ícone para Windows (16 a 256 px)
- `png/tasca-icon-*.png`: ícone de 16 a 1024 px. Para a app em Tauri, correr `cargo tauri icon png/tasca-icon-1024.png` para gerar todos os formatos (Windows, macOS, Linux).
- `tasca-lockup-*`: ícone e nome juntos, para fundo claro ou escuro
- `tasca-wordmark-*`: só o nome
- `tasca-banner-1200x630`: imagem para partilhas em redes sociais e GitHub
- `tasca-azulejo-pattern`: padrão de azulejo para fundos
- `tasca-cores.css`: paleta como variáveis CSS
- Letra: Inter Display ExtraBold (nome) e Inter (interface), grátis e open source.
