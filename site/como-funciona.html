Como funciona

Sem empresa no meio

A Tasca foi desenhada para que as tuas conversas sejam tuas. Esta página explica como, sem rodeios, para quem quer saber o que acontece por dentro.

O grupo vive no PC do anfitrião

Quem cria o grupo aloja-o numa base de dados SQLite no seu PC. Os membros ligam-se a ele pela rede iroh, que usa QUIC e atravessa a maioria dos routers. Quando não consegue, usa um relay, sempre cifrado.

A tua identidade é uma chave

A conta é um par de chaves ed25519. A mesma chave autentica a ligação de rede, por isso ninguém consegue fingir ser outra pessoa, nem o anfitrião.

Tudo é um evento assinado

Criar o grupo, entrar, enviar uma mensagem: cada coisa é um evento assinado pelo autor. Qualquer membro consegue verificar o histórico, e cada um guarda uma cópia. Se o PC do anfitrião desaparecer, o grupo pode ser recuperado.

Voz e vídeo pelo anfitrião

Cada pessoa envia o áudio (Opus) uma vez para o anfitrião, que o reencaminha aos outros. A supressão de ruído (DeepFilterNet ou RNNoise) corre no teu PC antes de o som sair. O vídeo usa H.264 ou VP8, com a placa gráfica quando possível.

Segurança

O que está protegido, e de quem

A tua conta

A chave da conta é cifrada com a tua palavra-passe (Argon2id, que demora de propósito para dificultar ataques) antes de sair do dispositivo. O servidor de contas guarda esse cofre fechado e não o consegue abrir: não conhece a tua palavra-passe nem a tua chave. As 12 palavras de recuperação recriam a chave e nunca saem do teu dispositivo.

As mensagens

As mensagens de grupo e as privadas são cifradas de ponta a ponta. Para chegarem mesmo com o anfitrião desligado, ficam também numa «caixa» no servidor, mas cifradas com chaves que só os membros têm. O servidor guarda bytes que não consegue ler.

As ligações

Todas as ligações entre dispositivos são QUIC com TLS, autenticadas pela chave de cada pessoa. O relay, quando é usado, só passa pacotes cifrados.

As atualizações

Cada versão é criada pelo GitHub Actions a partir do código público e assinada. A app só instala atualizações com a assinatura da Tasca.

Os plugins

Os plugins da loja são revistos e assinados pela equipa, e cada plugin só recebe as permissões que aceitares.

O que a Tasca não protege. Quem está no grupo lê as mensagens do grupo e pode copiá-las. O anfitrião vê quem está ligado e quando. Se alguém tiver acesso ao teu PC desbloqueado, tem acesso às tuas conversas: usa uma palavra-passe no Windows.

Encontraste uma falha?

Obrigado! Reporta-a em privado através do separador Security do GitHub, em vez de a publicar numa issue.

Tecnologia

NúcleoRust: identidade, eventos assinados, SQLite, rede P2P (crates/tasca-core)
Redeiroh (QUIC, travessia de NAT, relays)
AppTauri 2, a mesma base no Windows e no Android
InterfaceHTML, CSS e JavaScript simples, sem framework
VozOpus, DeepFilterNet, RNNoise
VídeoWebCodecs H.264 / VP8
