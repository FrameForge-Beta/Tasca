Visão geral

Um plugin da Tasca é JavaScript que corre dentro da app e se liga a ganchos: pontos onde a interface pergunta aos plugins se querem acrescentar alguma coisa, como uma opção num menu, uma secção num perfil ou um separador novo.

O objetivo é que quase tudo seja extensível: comandos no chat, bots, temas, botões, e até a disposição do ecrã. Plugins mais pesados vão poder ser escritos em WebAssembly (por exemplo em Rust).

Estado atual

A API de plugins está a nascer. Os ganchos desta página já existem na app. O carregamento de plugins a partir de uma pasta, as permissões e a loja estão em desenvolvimento. Os nomes podem mudar até à versão 1.0.

O primeiro plugin

Enquanto o carregamento por pasta não chega, podes experimentar os ganchos na pré-visualização da interface, que corre num browser normal com dados de teste:

  1. Clona o repositório: git clone https://github.com/FrameForge-Beta/Tasca
  2. Abre apps/desktop/ui/index.html no browser (ou corre um servidor local nessa pasta).
  3. Abre a consola do browser e cola o código abaixo.
  4. Carrega com o botão direito numa pessoa da lista de membros.
// Acrescenta "Dizer olá" ao menu de cada pessoa
window.tascaHooks.userMenu.push((pessoa, ctx) => [
  {
    label: `Dizer olá a ${pessoa.name}`,
    onClick: () => alert("Olá, " + pessoa.name + "!"),
  },
]);

Pronto: a opção aparece no fim do menu, separada por uma linha.

Ganchos

Todos os ganchos estão em window.tascaHooks. Cada gancho é uma lista: o teu plugin faz push de uma função. A Tasca chama todas as funções da lista quando precisa, e se uma der erro, ignora-a e continua.

Várias funções recebem um ctx (contexto):

ctx = {
  where: "card" | "full" | "menu",  // onde está a ser mostrado
  groupId: "…"                         // o grupo aberto, se houver
}

E uma pessoa, com pelo menos id, name, username, color e status.

userMenu

(pessoa, ctx) => itens[]. Acrescenta itens ao menu de botão direito de uma pessoa (lista de membros, mensagens, amigos, chamada). Devolve uma lista de itens de menu, ou uma lista vazia para não mostrar nada.

window.tascaHooks.userMenu.push((pessoa, ctx) => {
  if (!ctx.groupId) return [];
  return [{
    label: "Desafiar para xadrez",
    items: [
      { label: "Partida rápida (5 min)", onClick: () => desafiar(pessoa, 5) },
      { label: "Partida lenta (30 min)", onClick: () => desafiar(pessoa, 30) },
    ],
  }];
});

profileCard

(pessoa, ctx) => html. Acrescenta uma secção ao cartão de perfil (ctx.where === "card") e ao perfil completo ("full"). Devolve uma string de HTML, ou "".

window.tascaHooks.profileCard.push((pessoa) => {
  const elo = ratings[pessoa.id];
  if (!elo) return "";
  return `<div class="sec"><h4>Xadrez</h4><p>Elo ${elo}</p></div>`;
});
Escapa o texto. Nunca metas nomes ou mensagens de outras pessoas diretamente no HTML: escapa < > & " primeiro.

friendsTabs

() => [{ id, label, render() }]. Acrescenta separadores à página Amigos. render() devolve o HTML do separador.

window.tascaHooks.friendsTabs.push(() => [{
  id: "aniversarios",
  label: "Aniversários",
  render() {
    return `<p>O Rui faz anos amanhã 🎂</p>`;
  },
}]);

Itens de menu

Os menus da Tasca aceitam itens neste formato, ou "-" para uma linha separadora:

CampoO que faz
labelTexto do item
onClickFunção chamada ao escolher
hintTexto pequeno à direita, como um atalho
iconSVG do ícone
dangerMostra o item a vermelho
disabled, checkedDesligado; com visto
itemsSubmenu (lista de itens)
range{ value, min, max, step, fmt, onInput }: uma barra deslizante que não fecha o menu

Estilos e cores

Usa as variáveis CSS da Tasca para o plugin combinar com o tema escuro (Madeira) e o claro (Cal):

--vinho  #9B2C3F  cor principal, botões
--azulejo #2A5CAA  links, seleção, foco
--ocre   #E3A72F  menções, destaques
--oliva  #5E8C4A  online, sucesso
--fundo, --painel, --caixa, --texto  mudam com o tema

Manifesto Proposta

Cada plugin vai ter um tasca-plugin.json a descrevê-lo. Esta é a proposta atual:

{
  "id": "pt.exemplo.xadrez",
  "nome": "Xadrez",
  "versao": "1.0.0",
  "autor": "@marta_cx",
  "descricao": "Desafia amigos para partidas de xadrez.",
  "runtime": "js",
  "entrada": "main.js",
  "permissoes": ["ui.menus", "mensagens.enviar"]
}

Permissões Proposta

Um plugin só faz o que o utilizador aceitar ao instalá-lo. Ideias de permissões: acrescentar à interface, ler mensagens do canal aberto, enviar mensagens, usar a rede, guardar dados próprios. Um plugin sem permissões de rede não consegue enviar nada para fora.

Loja e revisão Planeado

A loja vai ser um catálogo num repositório do GitHub. Para publicar, abres um pull request com o teu plugin; a equipa revê o código, e se estiver tudo bem, o plugin é assinado e aparece na loja com o selo Verificado. A app recusa plugins da loja sem assinatura válida.

Plugins carregados à mão continuam a ser possíveis, com um aviso de que não foram revistos.

Boas práticas

  • Escapa sempre o texto de outras pessoas antes de o meter em HTML.
  • As funções dos ganchos correm muitas vezes: mantém-nas rápidas e sem pedidos de rede.
  • Escreve os textos em português de Portugal, curtos e claros, como o resto da Tasca.
  • Pede só as permissões de que precisas.
  • Tens uma ideia de gancho novo? Abre uma issue.
